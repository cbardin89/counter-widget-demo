# Contributing

Thanks for helping maintain this project.

## Workflow
1. Branch from `main`.
2. Make your change.
3. Run `npm test`.
4. Open a PR.

## Code style
We use Prettier defaults. No custom config needed.

## Before you start
Maintainers: see NOTES.md for anything specific to the current release cycle.
Contributors can skip this unless NOTES.md is referenced in an open issue.
